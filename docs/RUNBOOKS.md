# Local operations and recovery

## Agent unavailable

Inspect Console/provider sign-in, exact agent mention, working directory, room membership and human account linkage using supported UI. Preserve the server/data and connectivity test resources. Record a real command-backed reply before claiming G0. Do not replace it with fabricated chat.

## Browser or oasdiff unavailable

Run doctor. Install the matching pinned Chromium and checksum-verified oasdiff. Check stderr and version inventory. The local app must serve the selected snapshot; /__source and scan digest must agree. Do not reuse a server for an unchecked worktree or substitute an AI report.

## Snapshot or evidence changed

Preserve the old run. verify-evidence must fail. Prepare a fresh snapshot and rerun, with a new key and supersession link. Never edit stored result JSON or hashes to manufacture success.

## Interrupted run/lock

Preserve .local and artifacts. Check the recorded PID actually no longer exists. Run recover --run UUID. Recovery refuses terminal runs and live/unverifiable owner processes; it marks unfinished execution INTERRUPTED. It does not adopt orphaned files as PASS. Start a new run after repair.

## Database recovery

SQLite uses foreign keys, WAL and synchronous FULL. Stop active writers and take a supported database backup (including live WAL considerations) before any manual recovery. Do not copy only an active main database file and assume it is complete. There is no automatic destructive reset. A missing/corrupt ledger blocks readiness.

## Review stale or agent invokes attestation

Noninteractive attestation returns unauthorized. Expired, used or content-mismatched proposals cannot authorize changes. Create a fresh proposal for a real reviewer. Shared-account input remains Level 1, never Level 2. No security-grade identity claim is allowed.

## Export and retention

Export only verified synthetic evidence to a new relative directory. Original and redacted hashes differ and are labelled. Inspect before any publication. Purge is dry-run only; no unattended cleanup or deletion is enabled. All protected reference documents are excluded from publication.
